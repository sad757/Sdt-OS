# Лабораторная работа №1 по курсу «Операционные системы»

## Вариант 9

### Условие задания

В файле записаны команды вида: «число число число<endline>». Дочерний процесс
производит деление первого числа команды на последующие числа в команде, а
результат выводит в стандартный поток вывода. Если происходит деление на 0,
то тогда дочерний и родительский процессы завершают свою работу. Проверка
деления на 0 должна осуществляться на стороне дочернего процесса. Числа
имеют тип `float`. Количество чисел может быть произвольным.

### Структура проекта

```
.
├── parent.c
├── child.c
├── Makefile
├── test1.txt
├── test2.txt
├── test3.txt
└── README.md
```

### Сборка

Для сборки проекта выполните:

```bash
make
```

В результате будут собраны два исполняемых файла: `parent` и `child`.

Для очистки скомпилированных файлов:

```bash
make clean
```

### Запуск

Запустите родительский процесс:

```bash
./parent
```

После запуска введите имя входного файла (например, `test1.txt`) и нажмите
Enter. Программа прочитает команды из указанного файла, выполнит вычисления
и выведет результаты в стандартный поток вывода.

Пример работы:

```bash
$ ./parent
test2.txt
4.0000
2.0000
error: child terminated due to division by zero
```

### Формат входного файла

Каждая строка файла содержит последовательность чисел типа `float`,
разделённых пробелами. Первое число строки является делимым, все
последующие — делителями.

Пример:

```text
10.0 2.0 5.0
100.0 4.0
5.0 0.0 2.0
```

В этом примере третья строка содержит делитель, равный нулю, что приведёт
к завершению обоих процессов.

### Ограничения

- Используются только системные вызовы ОС Linux (`fork`, `pipe`, `read`,
  `write`, `open`, `close`, `dup2`, `execv`, `waitpid`, `exit`).
- Запрещено использование функций стандартной библиотеки `stdio.h`
  (`printf`, `fopen`, `fread`, `fwrite`, `snprintf` и т.д.).
- Комментарии в исходном коде отсутствуют.
- Динамическая память не используется: применяются буферы фиксированного
  размера (1024 байта).
- Максимальная длина одной строки (или отдельного числа) не должна
  превышать размер читаемого блока — 1024 байта.

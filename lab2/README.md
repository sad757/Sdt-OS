# Лабораторная работа №2 по курсу «Операционные системы»

## Вариант 9

### Условие задания

Рассчитать детерминант матрицы (используя определение детерминанта).
Реализовать последовательную и параллельную версии. Ограничение
максимального количества потоков задаётся ключом запуска.

### Сборка

	make
Запуск
Один запуск:

	./determinant -n 10 -t 4

Полный бенчмарк:

	./determinant -n 10 --bench

С CSV:

	./determinant -n 10 --bench --csv

Опции

-n N — размер матрицы N x N (1 ≤ N ≤ 12)

-t T — число потоков (по умолчанию 1)

-s S — seed генератора (по умолчанию 42)

-v — вывести матрицу

--bench — полный бенчмарк (T = 1, 2, 4, 8, 16, 128, 1024)
--csv — формат CSV (с --bench)

Ограничения

threads.h и std::thread запрещены

Используется pthread.h (POSIX Threads)

Матрица генерируется случайно с фиксированным seed

# Лабораторная работа №3 по курсу «Операционные системы»

## Вариант 9

### Условие задания

В файле записаны команды вида «число число число». Дочерний процесс
производит деление первого числа команды на последующие числа и
выводит результат в стандартный поток вывода. Если происходит деление
на 0, то дочерний и родительский процессы завершают свою работу.
Проверка деления на 0 выполняется на стороне дочернего процесса.
Числа имеют тип float. Количество чисел может быть произвольным.

Взаимодействие между процессами осуществляется через файл,
отображённый в память (memory-mapped file, mmap).

### Сборка

	make
Запуск:

	./parent
# затем ввести имя файла с командами, например:
test1.tx

Ограничения:

Размер отображаемого файла фиксирован: 4096 байт.

Размер читаемого блока: 1024 байта.

Максимальное количество чисел в одной строке: 64.

Строка не должна превышать 1024 байта.

Тесты:

test1.txt — корректные данные без деления на ноль.

test2.txt — содержит деление на ноль (процессы завершаются).

test3.txt — отрицательные числа и десятичные дроби.

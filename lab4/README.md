# Лабораторная работа №4 по курсу «Операционные системы»

## Вариант 9

### Условие задания

Создать динамические библиотеки, реализующие две функции:
1. `float cos_derivative(float a, float dx)` — производная cos(x) в точке a
   - Реализация 1: `(cos(a + dx) - cos(a)) / dx`
   - Реализация 2: `(cos(a + dx) - cos(a - dx)) / (2 * dx)`
2. `int prime_count(int a, int b)` — количество простых чисел на [a, b]
   - Реализация 1: наивный алгоритм
   - Реализация 2: решето Эратосфена

Библиотеки используются двумя способами:
1. При компиляции (программа `prog1_*`)
2. При исполнении через `dlopen`/`dlsym` (программа `prog2`)

### Сборка

	make

### Запуск

	./prog1_lib1   # программа 1, линкованная с lib1.so
	./prog1_lib2   # программа 1, линкованная с lib2.so
	./prog2        # программа 2, загружающая библиотеки в рантайме

### Команды

1 arg1 arg2 — вызов cos_derivative(a, dx)

2 arg1 arg2 — вызов prime_count(a, b)

0 — переключение между lib1.so и lib2.so (только для prog2)

exit / quit — выход
